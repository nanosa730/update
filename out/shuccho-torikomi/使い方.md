# 写真から取込 セットアップと使い方

## 1. スキルを登録（1回だけ）
claude.ai の 設定 → スキル → `shuccho-torikomi.zip` をアップロード（前の版があれば差し替え）。

## 2. マクロを入れる（1回だけ）
1. 出張整理のブック（.xlsm）を開き、Alt + F11
2. 前の版の「写真取込」モジュールがあれば、右クリック →「写真取込 の解放」（エクスポートは「いいえ」）
3. 「ファイル」→「ファイルのインポート」→ `写真取込.bas`
4. Alt + F8 →「取込ボタンを作る」→ 実行
   - 入力シートの O18 にボタンが2つでき、「取込記録」シートが作られる
5. 上書き保存

## 3. 毎日の使い方
1. 出張依頼の写真を Claude に送る（何枚でも。Claude がドライブの「出張取込」フォルダに保存）
2. 1日の終わりに、ブラウザで Google ドライブを開き、「出張取込」フォルダを右クリック →「ダウンロード」
   （zip がダウンロードフォルダに入る。解凍は不要）
3. Excel の **「ダウンロードから取込(まとめて)」** → 内容を確認して「はい」
   - 読んだ zip はダウンロードフォルダ内の「取込済」フォルダへ移る
   - 前に取り込んだ行は「取込記録」シートで判定して自動で飛ばす（フォルダの中身を消さなくてよい）

すぐ1件だけ入れたいときは、Claude の「取込|…」の行をコピー →「写真から取込」ボタン。

## 4. 来週、パソコン版 Google ドライブを入れたら
「取込記録」シートの **B1** に同期フォルダの場所を入れる（例：`G:\マイドライブ\出張取込`）。
以後はダウンロード不要。写真を送ったあと「ダウンロードから取込」を押すだけ。
