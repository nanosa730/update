# 写真から取込 セットアップ

## 1. スキルを登録（1回だけ）
claude.ai の 設定 → 機能（Capabilities）→ スキル → 「スキルをアップロード」で `shuccho-torikomi.zip` を選ぶ。

## 2. マクロを入れる（1回だけ）
1. 出張整理のブック（.xlsm）を開き、Alt + F11
2. メニュー「ファイル」→「ファイルのインポート」→ `写真取込.bas`
3. Alt + F8 →「取込ボタンを作る」→ 実行（入力シートの O18 にボタンができる）
4. 上書き保存

## 3. 毎回の使い方
1. 出張依頼の写真を Claude に送る
2. 返ってきた「取込|…」の行をコピー
3. 入力シートの「写真から取込」ボタン → 内容を確認して「はい」
