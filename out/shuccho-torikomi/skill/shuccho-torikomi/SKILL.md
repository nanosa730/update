# 出張依頼の写真 → 入力シート取込行

Excel「出張整理」ブックの **「写真から取込」ボタン**（マクロ `写真から取込`）に貼り付けるための行を作る。

**Googleカレンダーには登録しない。**（写真から予定を登録する普段の設定があっても、このスキルでは取込行を作るだけにする）

## 出力形式（厳守）

コードブロックに、1件1行で次の形式を書く。区切りは半角の縦線 `|`。

```
取込|月|日|先生|区分|1日／時間|行き先と内容
```

- 先頭は必ず `取込`（マクロはこの行だけを読む）
- **月・日**：半角数字（例 `10|28`）。複数日の行事は日ごとに1行
- **先生**：下の職員名簿の表記どおり（姓と名の間は全角スペース）
- **区分**：`出張` `年休` `職免` `職免2-9` `職免2-9-2` のどれか
- **1日／時間**：出張は空欄。年休・職免は `1日` または `1時間`〜`7時間`
- **行き先と内容**：`内容　時刻　場所` を全角スペースで区切って短く書く
  - 内容：会の名前を短くする（例「第54回東海・北陸地区公立学校教頭会研究大会…」→「教頭会研究大会」）
  - 時刻：受付時刻があれば受付開始、なければ開始時刻。`9:30` のように半角
  - 場所：会場名を短く（例「Niterra日本特殊陶業市民会館 フォレストホール」→「日本特殊陶業市民会館」）
  - 例：`中学校部会　館　9:30`、`授業公開　12:00　冨士中`、`区校長会　9:00　区役所`
- `|` は内容の中に使わない

## 読み取りの手順

1. **誰が行くか**を決める
   - 宛先・本文の「教頭先生の出席」「校長出席」「○○担当者」などから役職を読む
   - 役職を職員名簿で氏名にする。マーカーや手書きで名前が書いてあればそちらを優先
   - 決められないときは推測で埋めず、先生欄を `？` にして質問する
2. **日付**：令和→西暦はしなくてよい（月・日だけ）。複数日なら日ごとに行を分け、日ごとの会場・時刻を使う
3. **会場が複数**（分科会ごとなど）のときは、マーカー・丸囲みされた方を使う。なければ両方を併記して確認する
4. 取込行のあとに、**確認してほしい点**（推測した部分）を箇条書きで短く書く

## 出力例

```
取込|10|28|鬼頭　聡|出張||教頭会研究大会　12:30　日本特殊陶業市民会館
取込|10|29|鬼頭　聡|出張||教頭会研究大会分科会　8:30　ウインクあいち
```

確認してほしい点：
- 29日の会場はマーカーのある「ウインクあいち」（3〜5分科会）にしました

## 使い方の案内（ユーザーに伝える文）

コードブロックをコピー →  Excel の「写真から取込」ボタン → 内容を確認して「はい」。
