# 汐路中 年計のルール（毎年当てはめる）

## 学期と休業日（名古屋市立小学校及び中学校の管理運営に関する規則で決まっている）
| 区分 | 期間 |
|---|---|
| 第1学期 | 4月1日〜8月31日 |
| 第2学期 | 9月1日〜12月31日 |
| 第3学期 | 1月1日〜3月31日 |
| 学年始休業日 | 4月1日〜4月5日 |
| 夏季休業日 | 7月21日〜8月31日 |
| 冬季休業日 | 12月24日〜翌年1月6日 |
| 学年末休業日 | 3月25日〜3月31日 |

- 始業式は4/6以降の最初の登校日、1学期終業式は7/20以前の最後の登校日、2学期始業式は9/1以降の最初の登校日、2学期終業式は12/23以前の最後の登校日、3学期始業式は1/7以降の最初の登校日、修了式は3/24以前の最後の登校日が基本（学校で確認する）。
- スクリプトは設定ファイルに休業日を書かなくても、この期間を使う。

## 日課（B帯案・令和9年度から）
- 全日B帯（45分）。
- 月・水：6限後に学習枠25分（14:45〜15:10）→短学→清掃→15:30下校
- 火・金：6限後に短学→清掃→15:00下校。会議は15:00〜15:45なら6限を削らずにできる
- 木：5限まで→13:55下校→研修14:05〜14:55→会議15:00〜15:45

## 会議と研修
- 職員会議・学年会・運営委員会・現職教育・教科部会・進路指導委員会などは、同じ週の木曜に置く。
- 木曜が祝日・休業で移せない会議は、元の日（火・金なら15:00から）のままでよい。
- 研修は年35回、木曜に置く（会議記号の列に「研n」）。授業を優先し、研修のために授業は削らない。
- 研修の時間に会議をしてよいが、内容を研修の型（授業研究・校内研修・生徒理解の共有と協議・他校種との連携）に合わせる。事務連絡だけの会議は研修に数えない。
- 研修ができない木曜：教育相談・保護者会の期間、修学旅行、体育大会当日。
- 生徒委員会・生徒議会は木曜に置かない（生徒が13:55に下校するため）。

## 行事の決まり
- 教育相談・保護者会の期間は、全学年4日間で、木曜を含める（授業を多く残すため）。
- 大掃除は終業式・修了式の前日（前日が祝日なら直前の登校日）。
- 2学期の期末テストは11/18を含む日程にする。
- ノー部活ウィークは、定期テストの前1週間（テスト初日の7日前〜前日の登校日）。夏季・冬季の閉庁期間のノー部活ウィークは別。
- 修学旅行の事前指導は出発前。修学旅行の翌日は家庭学習日（3年）。
- 入学式の日、2・3年は授業日（家庭学習にしない）。
- 全国学調は4月中旬。日付が決まるまで仮置き（黄色）。
- 日付をまたぐ行事は矢印を使わず、毎日同じ内容を書く（土日・祝日には書かない）。
- 緑の塗りは土日・祝日だけ（長期休業の平日は塗らない）。

## 点検リスト（組み替えたあとに上から確認する）
1. 始業式前の会議（職1・学1・学2・教・部活など）が4/1以降の平日に入っているか
2. 祝日に当たって移した行事（赤字※）の移動先は適切か
3. 木曜の研修が35回とれているか。研修できない木曜はどこか
4. 木曜に生徒委員会・生徒議会が入っていないか
5. 土日に会議記号が残っていないか、同じ記号が重複していないか
6. 大掃除が終業式・修了式の前日か
7. 教育相談・保護者会が4日間で木曜を含んでいるか
8. 2学期期末テストが11/18を含んでいるか。ノー部活ウィークが各テストの前1週間になっているか
9. 同じ日に重なっている行事（準備と本番、テストと保護者会など）
10. 卒業式の日の前後（準備は前日、選挙管理委員会・小中連絡会は翌日など）
11. 外部の日程で未確定のもの（公立・私立入試、合格発表、全国学調、県民の日学校ホリデー、学校閉庁日）を赤字・仮置きにしているか
12. 宿泊行事・新規行事・廃止行事の反映
