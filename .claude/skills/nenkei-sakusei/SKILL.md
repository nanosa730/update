# 年間計画（年計）の作成

前年度の「年計」シートを次年度の暦に組み替え、学校のルールを当てはめた案を作る。そのあと先生と一緒に詰めて確定させる。月行事予定・授業数カウントは、年計が確定してから作る（年計の直しが後工程に波及して手戻りになるため）。

## 進め方

### 1. 最初に聞くこと（組み替えの前に）
日付で決まるものを先に確定させる。曜日合わせで自動配置すると、ずれて何度も直すことになるため。

- 着任式・始業式、入学式の日
- 1学期終業式、2学期始業式・終業式、3学期始業式、修了式
- 夏季・冬季・学年末休業の期間
- 卒業式の日（市・県の日程）
- 修学旅行の日程、宿泊行事（稲武など）の有無と時期
- その年度にやめる行事・新しく入る行事

わからないものは仮置きで進め、黄色の網かけにする。

### 2. 組み替えを実行する
`scripts/shift_nenkei.py` に設定ファイル（JSON）を渡して実行する。設定の書き方は `references/config_example.json` を見る。

```bash
python3 scripts/shift_nenkei.py config.json
```

スクリプトがすること：
- 行事を「同じ週・同じ曜日」に移す（日付は1日か2日前にずれる）
- anchors に書いた日は日付どおりに移す（始業式・終業式など）
- 始業式より前の会議（職1・学1など）は、次年度の4/1以降の平日に順番どおりに入れる
- 祝日を計算で入れ直し、祝日に当たった行事は次の登校日へ移して赤字（※）にする
- 職員会議・学年会・運営委員会・現職教育・教科部会などを同じ週の木曜へ移す
- 木曜の登校日に「研1〜研35」を入れる（教育相談・保護者会の期間、修学旅行、体育大会当日の木曜は除く）
- 緑の塗りは土日・祝日だけにする
- Excelが壊れないよう、余分なシート・壊れた名前定義・外部関数を取り除き、表示シートの設定を直す

結果は「作成メモ・要確認」シートに書かれる。祝日の計算は内閣府の公表と必ず照合する。

### 3. 点検する
`references/rules.md` の「点検リスト」を上から確認し、問題を一覧にして先生に見せる。直し方の提案も添える。

### 4. 先生の指示で直す
- 先生の指示は、まとめて受けて一度に直す。
- **PDFは毎回書き出さない。** 「PDFにして」と言われたときだけ書き出す。
- 先生が手で直したファイルが届いたら、それを正本にする。自動の組み替えをやり直して上書きしない。
- 直した内容は「作成メモ・要確認」シートに1行ずつ残す。
- 決まったことは `references/rules.md` に追記し、来年度に生かす。

### 5. 確定後
年計が確定したら、月行事予定 → 授業数カウント（各曜日・各コマの回数をそろえる）の順に作る。

## ファイルの形（年計シート）
- 月ごとに3列（日付・行事・会議記号）：4月B〜D、5月E〜G、…、3月AI〜AK
- 1日2行：4行目から。上の行に日付と行事1、下の行に曜日と行事2
- 文字色：赤字＝未定、橙字＝調整中。黄色の網かけ＝仮置き
- 会議記号の凡例は67行目。AN列以降の集計式は会議記号を数えている

## 参照ファイル
- `references/rules.md`：学校で決めたルールと点検リスト（毎回読む）
- `references/r9_log.md`：令和9年度を作ったときの経緯と決定事項（迷ったときの前例）
- `references/config_example.json`：設定ファイルの例
